# Лента на плеере Кинескопа

Вертикальная лента из 10 роликов живого грида, плеер Кинескопа. Хром как у экрана «Тревел лента»: шапка, действия справа, описание с «ещё», белые карточки 56px. У каждого ролика отель на 6–8 ноября для двоих, снимок поиска Туту от 20 октября. У «Секретов Розы Хутор» сверху ещё прямой рейс Москва → Сочи, `от 3338.05₽`. Следующий ролик начинает грузиться, пока играет текущий. Карточки открывают страницу отеля или выдачу авиа, не корзину.

```bash
cd tools/kinescope_feed
python3 -m http.server 8765
```

Открыть http://localhost:8765. Листать колёсиком, свайпом или стрелками. Звук включается кнопкой справа сверху.
