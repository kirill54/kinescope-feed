# Лента на плеере Кинескопа

Вертикальная лента из 10 роликов живого грида, плеер Кинескопа. Хром как у экрана «Тревел лента» в макете Streamerce: шапка, действия справа, автор, белая карточка 56px и полоска прогресса. На «Секретах Розы Хутор» карточка «Самолёт в Сочи», цена `от 3338.05₽` — прямой рейс Победа DP-5945 на 6 ноября, снимок поиска Туту от 19 октября. Карточка открывает выдачу, не корзину.

```bash
cd tools/kinescope_feed
python3 -m http.server 8765
```

Открыть http://localhost:8765. Листать колёсиком, свайпом или стрелками. Звук включается кнопкой справа сверху.
